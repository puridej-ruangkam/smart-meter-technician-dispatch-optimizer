# ติดตั้งแบบไม่ใช้อินเทอร์เน็ต (Windows)

โฟลเดอร์นี้มีไลบรารี Python ทุกตัวที่โปรแกรมต้องใช้ ติดตั้งได้โดยไม่ต้องต่ออินเทอร์เน็ต
ใช้กับ **Windows 64-bit + Python 3.14** เท่านั้น

## ขั้นตอน

1. **ติดตั้ง Python 3.14** (ข้ามได้ถ้าเครื่องมีอยู่แล้ว)
   - ไฟล์ติดตั้ง Python ไม่ได้อยู่ในโฟลเดอร์นี้ ต้องดาวน์โหลดจากเครื่องที่ต่ออินเทอร์เน็ตได้:
     https://www.python.org/downloads/windows/ → เลือก **Windows installer (64-bit)** ของรุ่น 3.14.x
   - วางไฟล์ `python-3.14.x-amd64.exe` ไว้ในโฟลเดอร์นี้ แล้วข้ามไปข้อ 2 (สคริปต์จะติดตั้ง Python ให้เอง)
   - หรือติดตั้งเองโดยดับเบิลคลิกไฟล์นั้น: ติ๊ก **Add python.exe to PATH** และตรวจว่า **tcl/tk and IDLE** ถูกเลือก (หน้าจอโปรแกรมต้องใช้)
2. **ดับเบิลคลิก `install_windows.bat`**
   - ถ้ายังไม่มี Python แต่มีไฟล์ติดตั้งในโฟลเดอร์นี้ สคริปต์จะติดตั้ง Python ก่อน แล้วให้ดับเบิลคลิกซ้ำอีกครั้ง
   - ติดตั้งไลบรารีจากโฟลเดอร์ `wheels/` (ใช้เวลาประมาณ 1–2 นาที)
   - ตรวจผลให้เอง ถ้าเห็น `All packages OK` แปลว่าติดตั้งเสร็จ
3. เปิดโปรแกรมด้วย `planner.bat` ในโฟลเดอร์โปรเจกต์

สิ่งที่ต้องมีในเครื่องอยู่แล้ว: Microsoft Excel (โปรแกรมสั่ง Excel ให้บันทึกไฟล์เอง)

## ในโฟลเดอร์นี้มีอะไร

| ไฟล์ | หน้าที่ |
|---|---|
| `install_windows.bat` | สคริปต์ติดตั้ง (ดับเบิลคลิก) |
| `requirements-lock.txt` | รายชื่อไลบรารีและรุ่นที่แน่นอน |
| `wheels/` | ไฟล์ติดตั้งไลบรารี 20 ไฟล์ (~90 MB): pandas, numpy, openpyxl, ortools, scipy, pywin32, pytest และไลบรารีที่ตัวเหล่านี้ต้องใช้ |

## ปัญหาที่พบบ่อย

- **"Python 3.14 64-bit was not found"** — เครื่องไม่มี Python หรือเป็นรุ่นอื่น (เช่น 3.12) ไฟล์ใน `wheels/` ใช้ได้กับ 3.14 เท่านั้น ให้ติดตั้ง 3.14 ตามข้อ 1 (ติดตั้งคู่กับรุ่นเดิมได้)
- **"tkinter is missing"** — เปิดไฟล์ติดตั้ง Python อีกครั้ง เลือก *Modify* แล้วติ๊ก *tcl/tk and IDLE*
- **ไฟล์ใน OneDrive ยังไม่ถูกดาวน์โหลด** — คลิกขวาที่โฟลเดอร์โปรเจกต์ → *Always keep on this device* แล้วรอให้ sync เสร็จก่อน

## สำหรับผู้ดูแล: อัปเดตไฟล์ในโฟลเดอร์นี้

ทำบนเครื่องที่ต่ออินเทอร์เน็ตได้ (Windows หรือ Mac ก็ได้) แก้รุ่นใน `requirements-lock.txt` ก่อนถ้าต้องการ แล้วสั่ง:

```
pip download --only-binary=:all: --platform win_amd64 --python-version 3.14 --implementation cp --abi cp314 --no-deps -d wheels -r requirements-lock.txt
```

ใช้ `--no-deps` เพราะ `requirements-lock.txt` มีครบทุกตัวแล้ว (รวม `colorama` และ `tzdata` ที่ Windows ต้องใช้)
ถ้าเพิ่มไลบรารีใหม่ ต้องเพิ่มไลบรารีที่ตัวนั้นต้องใช้ลงในไฟล์ด้วย ลบไฟล์รุ่นเก่าใน `wheels/` ออกหลังดาวน์โหลด
